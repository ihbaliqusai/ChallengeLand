# Home menu artwork

Active PNG artwork described below is shipped as pixel-identical lossless WebP.
Original PNGs remain for editing and are excluded from the runtime asset list.

`home_menu.png` was supplied from
`C:\Users\Qusai\Downloads\New folder (9)\5.png` and copied unchanged.

Flutter retains the original frame, close button and five illustrated menu
buttons. Native controls open the profile, leaderboard, daily rewards,
statistics, achievements and settings. The account header displays the actual
player name, rank, photo and connection state. Online-only actions retain their
connection checks, and reward badges show current availability. The unused
bottom-left slot retains the conditional rating entry for eligible players.

## Game modes artwork

`game_modes.png` was supplied from
`C:\Users\Qusai\Downloads\New folder (10)\5.png` and copied unchanged.

The original gold frame, title, close button and four mode cards are retained.

the available screen area without cropping its buttons.

## Weekly reward artwork

`weekly_reward.png` was supplied from
`C:\Users\Qusai\Downloads\New folder (16)\1.png` and copied unchanged.

Flutter composes the star background, ornamental corners, blue close button,
gold chest and glossy gold claim button from the original image. A vector clip
isolates the chest silhouette. Native labels and tiles display the actual week,
day, reward amounts, progress, countdown and receipt-backed claim state. The last
week contains only days 29 and 30. Compact landscapes use a shorter layout;
narrow screens stack the reward summary and wrap the daily roadmap.
